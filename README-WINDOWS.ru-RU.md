### Windows

#### Установка python + git
- Установите python >= 3.9 и git
- Если python установлен из Microsoft Store, команда "python setup.py install" завершится ошибкой, но этот шаг и не обязателен.
- WIN+R ```cmd```

#### Установка Winfsp (для fuse)
Скачайте и установите [отсюда](https://winfsp.dev/rel/)

#### Скачивание файлов и установка
```shell
git clone https://github.com/bkerler/mtkclient
cd mtkclient
pip3 install -r requirements.txt
```

#### Установка свежего UsbDk 64-Bit
- Установите обычный драйвер MTK Serial Port (или используйте стандартный драйвер Windows COM Port — убедитесь, что нет жёлтого восклицательного знака)
- Возьмите установщик usbdk (.msi) [отсюда](https://github.com/daynix/UsbDk/releases/) и установите его
- Проверьте при подключении устройства командой "UsbDkController -n", видно ли устройство с 0x0E8D 0x0003
- Отлично работает под Windows 10 и 11 :D

##### Скачивание и установка Build Tools:
    Перейдите на [страницу загрузки](https://visualstudio.microsoft.com/visual-cpp-build-tools) Visual Studio Build Tools.
    Скачайте установщик и запустите его.

###### Выбор необходимых компонентов:
    В установщике выберите рабочую нагрузку «Разработка классических приложений на C++».
    Убедитесь, что выбран компонент «MSVC v142 — набор инструментов C++ x64/x86 для VS 2019» (или новее).
    При желании можно также отметить «Windows 10 SDK», если он ещё не выбран.

###### Завершение установки:
    Нажмите кнопку «Установить», чтобы начать установку.
    Следуйте подсказкам установщика до конца.
    При необходимости перезагрузите компьютер.
